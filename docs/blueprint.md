# **应用名称**: LunaBloom

## 核心功能:

- 月经周期记录：记录月经开始和结束日期、流量强度和症状，以准确跟踪月经周期。
- 周期预测：基于记录的数据预测未来周期和排卵日期，提供生育窗口的见解。
- 生育体征跟踪：跟踪基础体温(BBT)和宫颈粘液等生育体征，以识别排卵日。
- 妊娠监测：通过每周见解和发育里程碑监测妊娠进展。
- AI症状分析：使用AI工具分析记录的症状，识别模式和潜在健康问题，提供个性化见解和建议。
- 个性化建议：根据跟踪的数据接收量身定制的建议，如生活方式调整或医生咨询。

## 风格指南:

- 主色调：柔和粉色(#F4C2C2)，营造温柔女性化的感觉。
- 背景色：淡紫色(#F0E6EF)，饱和度降低20%以保持柔和与平静。
- 强调色：薰衣草色(#D1B3C4)，亮度降低的类似色，用于突出交互元素。
- 正文和标题字体：'Alegreya'，人文主义衬线字体，营造优雅现代的感觉。
- 使用简洁、干净的图标，边缘圆润，采用较浅的粉色或紫色代表各种功能。
- 清洁直观的布局，充足间距增强可读性和用户体验。
- 微妙的动画和过渡效果，提供视觉反馈并提高参与度。
